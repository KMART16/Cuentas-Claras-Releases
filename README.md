# Cuentas Claras

Cuentas Claras es una aplicación de escritorio para la administración de cuentas por pagar, desarrollada para Ferretería La Nueva Familia.
La aplicación permite gestionar suplidores, proveedores, facturas, pagos y registros financieros desde una interfaz intuitiva, sin necesidad de una conexión constante a Internet.

### Funcionalidades principales

**Gestión de suplidores y proveedores:** Registro y administración de información de suplidores y proveedores.
**Administración de facturas:** Registro, consulta y seguimiento de cuentas por pagar y cuentas pagadas.
**Gestión de pagos:** Registro y administración de pagos realizados a suplidores y proveedores.
**Administración de cuentas bancarias:** Registro y gestión de las cuentas bancarias utilizadas por el negocio.
**Base de datos local:** Almacenamiento de información mediante SQLite, permitiendo utilizar la aplicación sin conexión a Internet.
**Interfaz de escritorio:** Aplicación diseñada para funcionar en computadoras con Windows.

### Descarga

Las versiones disponibles de Cuentas Claras se encuentran en la sección de Versiones y descargas.
Instalación en Windows:

  1. Acceda a la sección de versiones y descargas.
  2. Seleccione la versión que desea instalar.
  3. Descargue el archivo CuentasClarasSetup-{_version_}.exe correspondiente a esa versión.
  4. Ejecute el instalador descargado.
  5. Siga las instrucciones del asistente de instalación.

Una vez completada la instalación, abra Cuentas Claras desde el escritorio o el menú de inicio.

**_Nota: Windows podría mostrar una advertencia de editor desconocido debido a que el instalador todavía no cuenta con una firma digital._**

### Actualizaciones

Las nuevas versiones de Cuentas Claras estarán disponibles en este repositorio.
Para actualizar la aplicación:

  1.Descargue la versión más reciente.
  2. Cierre Cuentas Claras si se encuentra abierta.
  3. Ejecute el nuevo instalador.
  4. Complete el proceso de instalación.

Los datos de la aplicación se almacenan de manera independiente de los archivos de instalación, permitiendo conservar la información durante las actualizaciones.

### Tecnologías utilizadas

**Flutter** y Dart: Desarrollo de la aplicación de escritorio.

**SQLite**: Almacenamiento y administración de datos locales.

**Riverpod**: Gestión de estados de la aplicación.

**MVVM**: Arquitectura para separar la interfaz de usuario, la lógica de negocio y el acceso a los datos.

**Inno Setup**: Creación del instalador para Windows.

### Desarrollo

Este repositorio está destinado exclusivamente a la distribución de versiones de Cuentas Claras.
